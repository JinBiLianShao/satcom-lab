# SatCom Lab · 卫星通信 3D 可视化教学

> 一个**双击就能用**的卫星通信原理可视化教学项目：可旋转的 3D 地球 / 轨道 / 卫星 / 波束，
> 一张可点击的端到端系统框架全景图，以及 8 个「讲解 → 公式 → 拖参数 → 看实时图 → 做小测」的教学模块。

作者：连思鑫 · 面向通信 / 电子类学生与刚入行的工程师 · 中文

---

## 一、怎么打开（最简单的一步）

**直接双击 `index.html`**，用任意现代浏览器（Chromium / Chrome / Edge / Firefox）打开即可。

- 不需要 `npm install`，不需要 `npm run dev`，不需要起本地服务器，不需要联网。
- 不需要 VS Code 插件，不需要 Python，不需要构建。
- 地址栏显示 `file:///.../satcom-lab/index.html` 就是正确的打开方式。

> 为什么强调 `file://`：本项目刻意只用**经典 `<script>` 标签**加载（`type="module"` 在 `file://`
> 下会被浏览器的 CORS 策略拦住），并且不引用任何 CDN、字体、图片或 3D 库。所以断网也能用，
> 拷到 U 盘、发给同学、放进任意目录都能直接打开。

如果你改了窗口大小，画布会自动重排；窄屏（<900px）会自动切成「顶部导航 + 下方内容」的布局。

## 三、3D 场景怎么操作

| 操作 | 效果 |
|---|---|
| 鼠标左键拖拽 | 旋转视角（改 yaw / pitch，俯仰夹在 ±85°） |
| 滚轮 | 拉近 / 拉远 |
| 「⏸ 暂停 / ▶ 播放」 | 冻结 / 继续卫星轨道运动 |
| 「正视图 / 极视图 / 赤道视图 / 极轨视角」 | 四个预设视角 |
| 「切换卫星」 | 换一颗卫星画星地波束与覆盖锥 |
| 在「全系统框架」里点环节框 | 下方显示该环节的作用、关键参数、在链路中的位置 |

3D 是**现场算出来的**，不是贴图：透视投影、欧拉旋转、按深度排序的画家算法、Lambert 明暗、
背面剔除、经纬网采样、覆盖锥几何，全部由 `js/viz.js` 在 Canvas 2D 上手写完成，没有用 three.js。

**线框 + 低多边形是刻意选择**：教学目标是把「轨道倾角、覆盖锥、波束指向、三段落关系」看清楚，
比写实贴图更利于建立结构直觉，也才能保证零资源、可旋转、可验证。

## 四、整个系统框架讲了什么

「全系统框架」模块把一次卫星通信拆成端到端信号流（点击每个环节看详情）：

```
信源 → 信源编码 → 信道编码(FEC) → 调制 → 上变频 → 高功放(HPA) → 发射天线
     → 上行链路 → 卫星转发器（低噪放 + 变频 + 功放） → 下行链路
     → 地面接收天线 → 低噪放(LNB) → 下变频 → 解调 → 信道译码 → 信源译码 → 信宿
```

并叠加三条线索：

- **三段落**：地面段（发端 / 收端设备）、空间段（上行 / 下行传播 + 星上转发）、控制段（TT&C 测控、网管中心）。
- **频段**：C / Ku / Ka，上行与下行成对（上行频率略高，因卫星转发器本振下变频）。
- **多址**：FDMA / TDMA / CDMA，说明它们作用在「多个地面站共享上行」这一段。

想理解「为什么 GEO 打电话有延迟」「为什么 Ka 频段下雨会掉线」「为什么天线越大波束越窄」，
从这张图出发去看对应模块最顺。

## 五、公式与单位口径

所有数值都由 `js/physics.js` 的纯函数算出，同一份代码既驱动页面，也被
`tests/physics.test.mjs` 用教材标准式逐条核对（≥12 条基准断言）。

| 量 | 公式 | 单位 |
|---|---|---|
| 波长 λ | 0.3 / f | m（f 用 GHz） |
| 轨道速度 v | √(μ/(R_E+h)) | km/s |
| 轨道周期 T | 2π√((R_E+h)³/μ) / 60 | min |
| 自由空间损耗 FSPL | 92.45 + 20log₁₀f + 20log₁₀d | dB（f GHz, d km） |
| 天线增益 G | 10log₁₀[η(πD/λ)²] | dBi |
| 半功率波束宽度 θ | 70λ/D | deg |
| EIRP | Pt + Gt − L_feed | dBW |
| G/T | G − 10log₁₀T_sys | dB/K |
| C/N₀ | EIRP − FSPL − L_atm + G/T + 228.6 | dB-Hz |
| Eb/N0 | C/N₀ − 10log₁₀R_b | dB |
| 链路余量 | Eb/N0 − 门限 | dB |
| 斜距 d | √((R_E+h)² − (R_E cos E)²) − R_E sin E | km |
| 传播时延 τ | d/c × 1000 × hops | ms |
| 多普勒 f_d | −f·v_r/c | kHz |
| 香农容量 C | B·log₂(1+S/N) | bps |
| 覆盖半径 r | R_E·[acos(R_E cos E_min/(R_E+h)) − E_min] | km |

常数：光速 c = 299792.458 km/s，地球半径 R_E = 6371 km，
地心引力常数 μ = 398600.4418 km³/s²，玻尔兹曼常数 −228.6 dBW/K/Hz，
恒星日 86164.0905 s。GEO 高度 35786 km 对应周期 ≈1436 min（23h56m）。

**几何口径（两条容易算错，特地写清）**：

- LEO 最大多普勒不是直接拿轨道速度代，而是视线最大径向速度
  `vR_max = v·R_E/(R_E+h)`，再代入 `f_d = −f·v_r/c`。600 km / 2 GHz 约 ±46 kHz。
- 雨衰用简化 ITU 幂律 `A = k(f)·R^α·L·0.5`，其中 `k(f)=0.0001·f^2.2`、`α=1.05`。
  这是教学用简化式，不是工程链路设计的精确模型。

## 七、边界（不做什么）

- 不做 TLE / SGP4 真实星历与数值积分，用圆轨道解析式，目标是「可理解」而非「可定轨」。
- 不联网、不取遥测、不调在线地图或 3D 资源；全部数据本地、内存里。
- 不追求照片级渲染；线框 + 低多边形是为结构清楚而刻意选的。
- 雨衰、方向图旁瓣、香农限是教学简化模型，不用于真实链路设计与设备选型。

想深入某个公式的推导，看 `DESIGN.md` 第六节与各模块的「原理讲解」；想核对数值，
跑 `tests/physics.test.mjs`，它的期望值全部硬编码自教材标准式，不是从实现反推的。
